# Changelog

## 0.1.0

- Added a status bar countdown with click-to-start, pause, and resume.
- Added a menu button and hover controls for Start, Pause, Stop, Reset, and Set Time.
- Added duration input in minutes, MM:SS, H:MM:SS, and h/m/s units.
- Added per-workspace state recovery and completion notifications.
- Kept countdown timing accurate through computer sleep and editor reloads.
